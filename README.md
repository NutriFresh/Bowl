# NutriFresh Bowl — Premium GitHub Website

Upload all files/folders in this package to the root of your GitHub Pages repository (the same place as `index.html`).

## Structure
- `index.html` — website
- `styles.css` — premium responsive design
- `script.js` — cart/order interactions
- `assets/nutrifresh-logo.png` — NutriFresh GO logo
- `assets/products/` — ingredient-accurate product visuals

## Notes
- Product visuals intentionally use only the ingredients listed on the live NutriFresh menu.
- Razorpay is not hard-coded as a live payment integration; connect your secure Payment Link/backend before accepting payments.
- GitHub Pages can be refreshed after pushing these files.
