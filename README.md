# NutriFresh Bowl — GitHub Pages Website

## What's included
- Responsive single-page food website
- 6 product cards with generated premium food images
- Exact product names, prices and ingredient lists supplied for the NutriFresh Bowl menu
- Mobile navigation
- Product ingredient accordions
- SEO-friendly title and description
- Editable SVG brand logo
- No external libraries or build process required

## Files
- `index.html` — website
- `style.css` — responsive styling
- `script.js` — mobile navigation + year
- `assets/` — logo and 6 product images

## Publish on GitHub Pages
1. Create/open your GitHub repository (for example, `Bowl`).
2. Upload `index.html`, `style.css`, `script.js`, and the entire `assets` folder.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then **Save**.
6. Open the GitHub Pages URL shown by GitHub.

## Ordering links
The current package deliberately does not invent a phone number or ordering URL. Replace the `Get in Touch` / ordering area in `index.html` with your live WhatsApp, Swiggy, Zomato, phone or payment link when you are ready.

## Image note
The product images are website-ready PNGs generated for this NutriFresh Bowl project and kept visually consistent across the menu.
